# 西安手艺工坊：工序编辑、版本化阅读与安全确认

本项目在原西安文化静态介绍站基础上，增加“手艺专题”的全栈能力。系统不依赖第三方 npm 包，使用 Node.js 20 内置 HTTP 服务和 JSON 持久化，便于本地运行、验收和后续替换数据库。

## 快速开始

```bash
npm start
# 打开 http://localhost:3000/
# 访客阅读页：/craft.html?craftId=craft_shadow
# Web 管理页：/admin.html
# 开发管理员密钥：dev-admin-key（生产必须通过 ADMIN_KEY 覆盖）
ADMIN_KEY=更安全的密钥 PORT=8080 npm start
```

运行验收：

```bash
npm test
```

测试会启动临时服务并使用独立 `STORE_FILE`，覆盖 14 个服务端验收场景。

## 功能范围

### 访客阅读

- 手机优先的响应式阅读页面。
- 每个版本保存完整步骤文字、材料、注释、风险提示、媒体和文字替代方案。
- 按必需前置解锁步骤；拖动展示顺序不会改变依赖。
- 支持可选分支、互斥选择、`and` / `or` 汇合条件。
- 必须先显式确认当前版本的原有风险提示，才能确认步骤；阅读进度由服务端持久化，返回每一步是否可确认、是否已确认及阻塞原因。
- 网络失败时仅在本机临时排队；恢复后由服务端按版本和步骤哈希核验，版本变更的离线迟到确认返回 409，不覆盖新进度。
- 阅读确认只表示“已阅读”，页面和数据中均明确：不代表具备实际操作资格。

### Web 管理

管理员通过 `x-admin-key` 请求头认证（管理页顶部输入密钥），可管理：

- 材料：新增、停用/恢复、删除。被草稿或历史步骤版本引用的材料拒绝删除。
- 媒体：登记图片、音频、视频；维护可用状态、授权状态、审核状态、替代文字和完整文字方案。
- 字幕/口播：换版会生成新版本号；已发布步骤继续锁定旧字幕，新发布必须重新选择并审核。
- 注释：创建、通过或驳回；只有审核通过的注释进入公开版本。
- 工序：编辑稳定步骤 key、标题、正文、说明、必需前置、分支组、汇合条件、材料、媒体和替代方案。
- 排序：字段集可拖拽，也可用 `Alt + ↑ / ↓` 键盘排序；排序只影响 `order`，依赖仍来自前置字段。
- 发布：服务端重新执行全部校验后生成不可变教程版本。
- 回滚：历史版本只能“分叉”为新草稿并重新审核；授权撤销的素材不会因回滚重新可用。

## 版本与进度迁移

发布时选择两种模式：

1. **整个教程冻结（frozen，主版本）**
   - 新版本作为完整不可变快照。
   - 学习者可以继续旧版；选择升级后，新版所有步骤重新确认。
   - 旧勾选仅保留在历史记录中，不会被推断为新要求已完成。

2. **按步骤升级（stepwise，次版本）**
   - 每个步骤有稳定 `key`、步骤修订号 `revision` 和内容哈希 `variantHash`。
   - 只有 key 与哈希都未改变、且在新图中依赖仍成立的确认可迁移。
   - 新增、删除、合并、拆分、文字/材料/媒体/前置/分支/汇合要求变化的步骤重新确认。
   - 汇合步骤不会因为旧步骤曾被勾选而自动完成。

## 服务端发布校验

发布前在服务端检查：

- 步骤 key 唯一，标题和完整文字有效。
- 必需前置存在，禁止自依赖、重复前置、循环和不可达节点。
- 可选步骤必须属于分支组；同组分支互斥。
- 每个分支组必须有唯一汇合步骤；汇合依赖和分支清单必须匹配。
- 汇合条件只能是 `and` 或 `or`，`or` 必须写明判定说明。
- 必需材料必须存在且处于 active；缺材料不能发布。
- 媒体必须已审核、可用、授权有效；音视频必须锁定字幕/口播版本。
- 无媒体时必须提供明确文字替代方案，页面始终有完整文字。
- 工艺内容、步骤、注释和风险提示均须审核通过。

历史版本读取时再次检查媒体当前授权和可用状态。若后来撤销授权或媒体失效，公开接口清空播放 URL，仅展示文字替代及不可用原因，历史链接不能绕过撤销。

## 数据与接口概览

数据默认持久化到 `data/store.json`，写入采用临时文件原子替换。

### 公开接口

- `GET /api/crafts`
- `GET /api/crafts/:craftId?versionId=...`
- `POST /api/progress/start`
- `POST /api/progress/:progressId/acknowledge-risk`
- `GET /api/progress/:progressId`
- `POST /api/progress/:progressId/confirm`
- `POST /api/progress/migrate`

### 管理接口（需要 `x-admin-key`）

- `GET /api/admin/state`
- `POST/PATCH/DELETE /api/admin/materials...`
- `POST/PATCH/DELETE /api/admin/media...`
- `PUT /api/admin/media/:id/captions/:lang`
- `POST/PATCH /api/admin/annotations...`
- `GET/PUT/DELETE /api/admin/crafts/:id/draft`
- `POST /api/admin/crafts/:id/publish`
- `POST /api/admin/crafts/:id/rollback`

## 无障碍与发布底线

- 语义化 HTML、跳到主内容链接、可见焦点、键盘可操作控件。
- 图片有替代文字，音视频有文字替代，字幕/口播以文本展示。
- 移动端不把媒体作为获取文字信息的唯一入口。
- 新发布必须包含当前可用媒体，或提供明确文字替代方案。
- 所有风险提示采用经审核内容，阅读页显著展示“阅读确认不是操作资格”。
