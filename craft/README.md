# 手艺专题（工序编辑 · 版本化阅读）

零依赖 Node.js 全栈模块，为西安文化站新增「手艺专题」：编辑在 Web 端管理工序、材料、注释与媒体；
后端校验依赖图（必需前置、可选分支、互斥、汇合、循环、缺材料、媒体合规）并持久保存步骤版本；
访客在手机上阅读完整文字并确认进度。**阅读确认仅表示已阅读，不代表获得实际操作资格。**

## 运行

```bash
# Node 18+（开发环境为 Node 20），无需 npm install
ADMIN_KEY=你的管理密钥 node craft/backend/server.js
# 浏览器
#   访客阅读（移动端优先）： http://localhost:3000/
#   Web 管理端：             http://localhost:3000/admin
#   文化站原页面：           http://localhost:3000/index.html
```

首次启动自动写入种子数据（皮影雕刻示例：必需前置 + 可选互斥分支 + any/all 汇合 + 不可用视频但带文字替代；
另含一个冻结模式示例教程）。删除 `craft/backend/data.json` 即可重置。

## 验收测试

```bash
node craft/test/acceptance.test.js
```

覆盖 40+ 条断言，含需求点名的五个场景：

1. **并发删除被引用材料** → 同事务引用检查，`409 MATERIAL_IN_USE`；
2. **视频不可用** → 阅读端展示文字替代；无替代时发布 `409 MEDIA_UNAVAILABLE_NO_ALT`；
3. **字幕换版** → 钉用撤版字幕且无替代被拒；钉用新版字幕可发布；
4. **步骤分叉后回滚** → 丢弃草稿回到已发布线，学习者进度不受影响；
5. **离线进度迟到** → 旧版本号确认 `409 STALE_VERSION` 且不落库，重读新版才可确认（重复提交幂等）。

另含：依赖循环、悬空依赖、互斥组不一致、汇合 any/all、缺材料/未审核材料、
合并步骤迁移不可沿用旧勾选、冻结历史链接遇授权撤销返回 410、完整文字/风险提示闸门、管理鉴权。

## 两种升级模型（详见 DESIGN.md 第 4 节）

- **按步骤升级（stepwise）**：每步独立版本；未读步骤随发布更新，已读记录保留旧版号；
  离线迟到的旧版确认被服务端拒绝，要求重读。
- **整个教程冻结（frozen）**：开始即绑定整体快照；新版本需学习者显式迁移；
  普通修订可沿用勾选，**拆分/合并步骤必须重新确认**——合并步骤绝不凭旧勾选自动认定。

## 合规与可访问性

- 仅展示经审核的工艺介绍与原有风险提示；注释审核后才公开。
- 每个步骤都有完整文字；支持跳转链接、焦点样式与纯键盘操作。
- 撤销授权的素材在任何历史链接下均返回 410，不得绕过。
